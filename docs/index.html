How to check, correct and upload

Check items

  1. Click Download Excel.
  2. In the yellow Check column choose Confirmed, Not theirs, Not AI or Is AI. The Items To Check tab holds the doubtful ones.
  3. Fix wrong cells (type, title, year, venue) directly.
  4. Add your name under Reviewed by.

Upload

Click Upload (you need edit access to the GitHub project), drop the saved file, and press Commit changes. Your changes are applied within a few minutes and kept every month. Other teams' workbooks in the same template, such as Google Scholar collections, can be uploaded the same way.

Edit one item

The Edit link opens a pre-filled correction request with the item's ID. Anyone can use it; a maintainer applies it.

Where the data comes from

City Tech department directories and faculty bios, OpenAlex, CUNY Academic Works, ORCID, NSF and NIH awards, plus uploaded workbooks. Updated on the 1st of every month. Items are sorted by type with rules; no AI model is used.
